# Context management skill

Start with `AGENTS.md` and the two L1 rules. Select one workflow. Load only the
stage skill and conditional rules named by the workflow. Search for symbols and
tests before reading large files. Treat `openapi.yaml`, migrations, approved
specs, and user requirements as authoritative over inferred legacy behavior.

At handoff, keep the summary short and point to evidence paths rather than
copying full logs or source files into artifacts.
